## 프로젝트 개요

- **제목:** 네트워크에서 행동까지, 10대 익명 투표앱 실패의 원인과 온보딩 전략 제언
- **기간:** 2025.07.07 ~ 2025.08.13
- **내용:** 10대 대상 익명 투표앱의 실제 데이터를 활용해 **서비스가 실패한 원인**을 분석. 소셜 네트워크 분석·클러스터링·유저 행동 분석으로 초기 온보딩 단계의 문제를 파악하고, 이를 바탕으로 온보딩 전략을 제안
- **사용 툴:** Python (pandas, numpy, matplotlib, sklearn)
