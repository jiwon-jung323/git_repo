# 인턴십 업무 코드 (보안 정책 적용본)

| 항목 | 내용 |
|------|------|
| **기간** | 2025.11 ~ 2026.01 |
| **유형** | 기업 인턴십 |
| **스크립트** | [scripts/](./scripts/) |

> `codepreview`는 저장소 정리용 폴더명일 뿐, 별도 프로젝트명이 아닙니다.

## 개요

인턴십 기간 동안 작성한 **실제 업무 코드**를 기업 보안 정책에 맞게 수정·정리한 자료입니다.  
DB 연결 정보, 파일명, 컬럼명, 식별 가능한 업무 세부사항 등은 **마스킹** 처리했으며, 공개 허용 범위 내에서만 포함되어 있습니다.

B2B 거래·입찰 플랫폼 데이터를 대상으로 **추출 → 전처리 → 키워드 정규화 → 카테고리 매핑 → 지표 산출** 파이프라인을 구축·운영한 작업입니다.

## 스크립트 구성

### 1. 데이터 추출 및 기간별 필터링

| 파일 | 설명 |
|------|------|
| `6month_masked_sample.py` | 6개월 단기 데이터 추출 샘플. 주문·상품·참여 정보 병합, 유효 참여 건 필터링 |
| `2_year_masked.py` | 2년 데이터 전처리 및 키워드 정제. 제외 키워드 필터, 상품명·규격 텍스트 정제 |
| `5_year_masked.py` | 5년 장기 데이터 추출. 비물품 키워드 1차 필터링 |

### 2. 키워드 정규화 및 카테고리 매핑

| 파일 | 설명 |
|------|------|
| `keyword_2year_masked.py` | 텍스트 정규화(NFKC, 소문자, 특수문자 제거) 및 유사 상품명 그룹화 |
| `keyword_5year_masked.py` | 5년치 데이터 키워드 1차 매핑 |
| `keyword_clean_masked.py` | 최빈값 기반 대표 클래스 선정, 동률 건 분리 |
| `2year_price_keyword_masked.py` | 동률 카테고리 확정, 타겟군 태그 생성 |
| `keyword_exploration_masked.py` | 특수 키워드 및 예외 타입 탐색 |

### 3. 도메인 매칭 및 머신러닝 유사도 분석

| 파일 | 설명 |
|------|------|
| `data_matching_masked.py` | 특정 도메인 분리, 다중 분류 조합 추출 |
| `product_id_merge_final_masked.py` | 태그 상호 배제 적용, 상품 마스터·키워드 데이터 병합 검증 |
| `category_bert_matching_masked.py` | BERT 임베딩 기반 상품명 매칭 (KNN + 코사인 유사도) |

### 4. 지표 산출

| 파일 | 설명 |
|------|------|
| `trust_score_masked.py` | 거래 참여·계약·거래액 등 활동 지표 기반 신뢰 점수 산출 |

## 주의사항

- 원본은 인턴십 당시 사내 환경에서 작성한 코드이며, 여기에 포함된 버전은 **보안 정책에 따라 수정된 사본**입니다.
- 모든 스크립트는 **샘플 CSV 파일명**을 사용하며, 실제 운영 데이터는 포함되어 있지 않습니다.
- 로직·처리 흐름은 당시 업무를 반영하지만, 식별 가능한 정보는 제거·대체했습니다.
